Shieldy's Message Sort

Messages fall from the top. Sort each one — Block it if it's a red flag, or mark it Safe if it's fine — before it crosses the line. Get it right, learn why. Get it wrong, and Shieldy will explain what you missed.

How to play

  • 🛡️ Tap Block for messages with red flags — secrecy, urgency, personal questions, "too good to be true"
  • ✅ Tap Safe for normal, friendly messages
  • ❤️ You have 3 lives — miss too many red flags and it's game over
  • ⚡ It speeds up as your score climbs. Good luck, Knight!
